# Express TS Template

# Lib

- prisma
- swagger-ui-express
- openapitools
- bcryptjs

### Run

1. clone
2. install deps
3. create `prisma/dev.db` file
4. run `sh npm run migration:dev`
5. run `sh npm run dev`

Here, uou can access the [`api documentation`](http://localhost:8080/api-docs) after running the app
